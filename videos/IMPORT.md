# 视频导入说明

站点的视频清单由 `scripts/gen_manifest.py` 在构建时生成，
它只做一件事：扫描 `videos/` 目录，输出 `videos.json`。

因此导入视频有两种方式，可以混用。

---

## 方式一：导入本地文件

把视频放进 `videos/` 目录即可，目录结构决定作者和标题。

### 1. 扁平命名（推荐小批量）

```
videos/
├── 小明-第一次做菜.mp4
├── 小红_旅行日记.mp4
└── 阿强 — 深夜食堂.mp4
```

文件名按 **第一个分隔符** 切成两段：

| 文件名 | 作者 | 标题 |
| --- | --- | --- |
| `小明-第一次做菜.mp4` | 小明 | 第一次做菜 |
| `小红_旅行日记.mp4` | 小红 | 旅行日记 |
| `阿强 — 深夜食堂.mp4` | 阿强 | 深夜食堂 |
| `随手拍.mp4` | 未知UP主 | 随手拍 |

支持的分隔符：`-` `_` `—` `–` `|`，两侧空格可有可无。

### 2. 目录命名（推荐批量）

```
videos/
└── 小明/
    ├── 第一次做菜.mp4
    ├── 第一次做菜.jpg      ← 封面
    └── 周末骑行.mp4
```

一级目录名 = 作者，文件名 = 标题。目录形式优先级高于文件名切分，
所以 `小明/第一次做菜.mp4` 的作者是「小明」，而不是「小明」被再切一次。

### 3. 封面

在视频**同目录、同文件名**下放一张图片即自动识别：

```
第一次做菜.mp4
第一次做菜.jpg     ← 自动作为封面
```

支持 `.jpg` `.jpeg` `.png` `.webp`。没有封面时用视频首帧。

### 4. 支持的视频格式

`.mp4` `.webm` `.mov` `.m4v` `.mkv`

> `.mkv` 浏览器兼容性差，建议转成 `.mp4`（H.264 + AAC）。

## 方式二：导入 JSON（走 CDN）

在 `videos/` 目录下任意位置放一个 `.json` 文件，
脚本会把里面的条目直接合并进清单。

```json
[
  {
    "author": "小刚",
    "title": "远程视频",
    "url": "https://cdn.example.com/a.mp4",
    "cover": "https://cdn.example.com/a.jpg",
    "desc": "这段描述会显示在标题下方"
  },
  {
    "author": "小美",
    "title": "云端探店",
    "url": "https://cdn.example.com/b.mp4"
  }
]
```

也支持包一层对象：

```json
{
  "videos": [
    { "author": "小刚", "title": "远程视频", "url": "https://cdn.example.com/a.mp4" }
  ]
}
```

### 字段表

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `url` | ✅ | 视频直链，`http(s)://` 或站内相对路径 |
| `author` | ❌ | 作者名，缺省为「未知UP主」 |
| `title` | ❌ | 标题，缺省为「未命名」 |
| `cover` | ❌ | 封面图链接，缺省用视频首帧 |
| `desc` | ❌ | 描述，最多显示两行 |

### 关于 CDN

- 必须是**直链**，不能是网页地址或需要登录的分享页。
- 需要允许跨域播放，否则部分浏览器会拒绝加载。
- 建议用 HLS 时也先转成 `.mp4`，当前播放器只按普通 `<video>` 处理。
- 同一个 `url` 只会入列一次，重复写不会产生重复项。

## 常见问题

**作者全变成「未知UP主」**
文件名里缺少分隔符。`小明第一次做菜.mp4` 无法切分，
需要写成 `小明-第一次做菜.mp4`，或者改用目录形式。

**仓库太大 / Pages 部署失败**
Pages 对仓库体积敏感。把视频传到 CDN，本地只留 JSON 清单。

**页面提示"加载失败"**
`videos.json` 没生成，通常是 Actions 里 `gen_manifest.py` 报错，
去 Actions 日志里看 Python 步骤的输出。
